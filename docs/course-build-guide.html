▦ ដ្យាក្រាមស្ថាបត្យកម្ម · Architecture Diagram

រូបភាពសង្ខេបពីរបៀបដែលផ្នែកនីមួយៗភ្ជាប់គ្នា។ How the pieces connect.

📍 ចំណុចសំខាន់៖ គ្រប់ការស្នើ scope តាម org_id (cookie ?org=slug) → ស្ថាប័ននីមួយៗឃើញតែទិន្នន័យខ្លួនឯង។ Server កត់ត្រាដោយ server timestamp។

→ Flow ការងារ · System Flow

ពន្យល់ជាចំណុចៗ ងាយបង្រៀន។ The end-to-end flow, point by point.

A. Flow ចុះវត្តមាន (Attendance)

  • Owner បង្កើតស្ថាប័ន → ផ្តល់ link /?org=slug និងពាក្យសម្ងាត់ Admin។
  • Admin បង្កើតបុគ្គលិក (Employee ID) · កំណត់ទីតាំង · ជ្រើសវិធីចុះវត្តមាន។
  • បុគ្គលិក បើក app → បញ្ចូល Employee ID (activate) → ចុះឈ្មោះមុខ (face)។
  • Check-in៖ GPS ត្រូវនៅក្នុងតំបន់ → ផ្ទៀងផ្ទាត់ (មុខ/QR/កាត/NFC)។
  • Server កត់ត្រាដោយ server timestamp (ការពារការបន្លំម៉ោង) → ផ្ញើ Telegram (ក្រុម + DM)។

B. Flow អត្តសញ្ញាណ (Identity)

  • គោលគឺ Employee ID (មិនមែន Telegram ID) — ប្តូរ Telegram ក៏មិនបាត់។
  • មុខ៖ AI គណនា descriptor 128 → server ផ្គូផ្គងនឹងបុគ្គលិកទាំងអស់ (auto-match)។
  • កាត QR៖ encode SECATT-EMP:code:token (token មានហត្ថលេខាសម្ងាត់)។
  • NFC៖ serial កាត ↔ បុគ្គលិក (ចុះបញ្ជីមុន)។

C. Flow ប្រាក់ខែ (Payroll)

  • Attendance → គណនា ថ្ងៃ/យឺត/ម៉ោង (តាមម៉ោងកំណត់ Asia/Phnom_Penh)។
  • ប្រាក់ខែ = គោល (ខែ) ឬ rate×ម៉ោង (hourly) + ថែម − កាត់ (adjustments)។
  • Payslip ផ្ញើតាម Telegram — ដោយដៃ ឬ cron ថ្ងៃ payday។

D. Flow Multi-tenant

  • គ្រប់ table មាន org_id។ org មកពី cookie (?org=slug)។
  • API នីមួយៗ scope តាម org → ទិន្នន័យស្ថាប័នដាច់ដោយឡែក ១០០%។
  • Config (geofence/payroll/QR) រក្សាក្នុង row organizations per org។

Stack: Next.js 15 (App Router, TypeScript), Tailwind CSS v4, Supabase (Postgres), Telegram Bot (Telegraf).

GPS Geofence + ផែនទី · Mapទីតាំង, Haversine, radius, Leaflet
🇰🇭 ខ្មែរ
បន្ថែមមុខងារ GPS៖ ទាញទីតាំងបុគ្គលិក (navigator.geolocation), គណនាចម្ងាយទៅការិយាល័យដោយ Haversine formula។

ប៊ូតុង "ចូលធ្វើការ (IN)" និង "ចេញធ្វើការ (OUT)" disabled បើនៅក្រៅតំបន់។
🇬🇧 English
Add GPS: read the user's location (navigator.geolocation), compute distance to the office using the Haversine formula.
Show "within allowed zone / too far" based on a radius. Add a Leaflet map (OpenStreetMap) with the office marker + radius circle.
"Check IN" and "Check OUT" buttons are disabled when outside the zone.

AI ផ្គូលមុខ · Face Recognitionface-api.js, enroll, auto-match

🇬🇧 English
Add AI face recognition with @vladmandic/face-api. Copy the models into /public/models.
Build a "Face Registration" modal: open the front camera, compute a 128-d face descriptor, store in localStorage + Supabase (face_enrollments).
On selfie check-in: capture face → server auto-matches against all enrolled employees (threshold 0.5). If no match, block submit.

🇰🇭 ខ្មែរ

ផ្ទៃបុគ្គលិក៖ ផ្ទាំង "ភ្ជាប់គណនី" បញ្ចូល Employee ID → activate (រក្សា localStorage)។ បន្ទាប់ទើបឱ្យចុះឈ្មោះមុខ និងចុះវត្តមាន។

🇬🇧 English
Create an employees table (unique code, name, department, telegram_id, active). Attendance keyed by employee_code + server timestamp.
Employee side: an "Activate" screen to enter the Employee ID → activate (store in localStorage). Then allow face enrollment and check-in.
Face auto-match returns the employee → record attendance for them.

🇬🇧 English
Create a Telegram Bot (Telegraf) as a webhook (app/api/bot). /start opens the Mini App, /link <EmployeeID> binds telegram_id.
On check-in send to two places: the admin group AND a private DM to the employee (if linked). Auto-link telegram_id when the app opens inside Telegram.

🇰🇭 ខ្មែរ
បន្ថែម tab របាយការណ៍វត្តមានប្រចាំខែ (ថ្ងៃ/យឺត/ម៉ោង, Export CSV) និង tab ប្រាក់ខែ។
ប្រាក់ខែ៖ ប្រភេទថេរ(ខែ) ឬ គិតម៉ោង per employee; យឺត/អវត្តមាន auto តាមម៉ោងកំណត់ (Asia/Phnom_Penh); ថែម/កាត់ (adjustments)។
Payslip ផ្ញើ Telegram — ដោយដៃ ឬ cron ថ្ងៃ payday (vercel.json)។ គ្រប់ query paginate ($.range) ដើម្បីកុំជាប់ 1000-row។
🇬🇧 English
Add a monthly attendance report tab (days/late/hours, CSV export) and a payroll tab.
Payroll: fixed-monthly OR hourly per employee; auto late/absent from work-hour settings (Asia/Phnom_Penh); add/deduct adjustments.
Send payslips via Telegram — manually or by a payday cron (vercel.json). Paginate every query (.range) to avoid the 1000-row cap.

ជំនួស + Timesheet + Excelsubstitute, part-time manual hours, import
🇰🇭 ខ្មែរ
បន្ថែម៖ (1) ការជំនួស — ពេល check-in ជ្រើស "ជំនួសឱ្យ X"; អ្នកធ្វើពិតទទួលប្រាក់, កត់ substitute_for។
(2) Timesheet — Admin បញ្ចូលម៉ោងតាមថ្ងៃសម្រាប់ part-time + កាលវិភាគប្រចាំសប្តាហ៍។
(3) Excel import — upload .xlsx (SheetJS) បញ្ចូលបុគ្គលិក + ប្រាក់ច្រើនម្ដង, មាន template។
🇬🇧 English
Add: (1) Substitution — at check-in pick "covering for X"; the real worker is paid, store substitute_for.
(2) Timesheet — admin enters per-day hours for part-timers + a weekly schedule.
(3) Excel import — upload .xlsx (SheetJS) to bulk add employees + pay, with a template.
10
Multi-tenant + Ownerorganizations, org_id scoping, /owner
🇰🇭 ខ្មែរ
ធ្វើ multi-tenant ដោយ "shared DB + org_id"។ បង្កើត table organizations (slug, name, admin_password, geofence/payroll/qr_secret JSONB, attendance_methods JSONB)។
បន្ថែម org_id លើគ្រប់ table; ទិន្នន័យចាស់ → org "default"។ org មកពី cookie (?org=slug)។ រាល់ API scope តាម org_id។
បង្កើតផ្ទាំង /owner (OWNER_PASSWORD) គ្រប់គ្រងស្ថាប័ន៖ បង្កើត/កែ, កំណត់ admin password, toggle វិធីចុះវត្តមាន ៥, copy link app/admin។
🇬🇧 English
Make it multi-tenant via "shared DB + org_id". Create an organizations table (slug, name, admin_password, geofence/payroll/qr_secret JSONB, attendance_methods JSONB).
Add org_id to every table; existing data → the "default" org. Org comes from a cookie (?org=slug). Scope every API by org_id.
Build an /owner panel (OWNER_PASSWORD) to manage orgs: create/edit, set admin password, toggle the 5 attendance methods, copy app/admin links.
11
កាត QR / NFC · Employee Cardsprintable QR cards, signed token, NFC register
🇰🇭 ខ្មែរ
បន្ថែម tab "កាតបុគ្គលិក"៖ បង្កើតកាត QR ឱ្យបុគ្គលិកម្នាក់ៗ (រូប+ឈ្មោះ+លេខ+QR), ព្រីនទាំងអស់។
QR encode "SECATT-EMP:code:token" ដែល token ជាហត្ថលេខាសម្ងាត់ (sha256 ជាមួយ org secret) — ការពារក្លែងបន្លំ។
ចុះ NFC៖ ភ្ជាប់ serial កាតទៅបុគ្គលិក (Web NFC ទូរស័ព្ទ ឬ USB reader)។
🇬🇧 English
Add a "Employee Cards" tab: generate a QR ID card per employee (photo+name+code+QR), print all.
The QR encodes "SECATT-EMP:code:token" where token is a signature (sha256 with the org secret) — prevents forgery.
NFC registration: bind a card serial to an employee (phone Web NFC or a USB reader).

Kiosk + USB Readerfull-screen station, HID reader, auto IN/OUT
🇰🇭 ខ្មែរ
បង្កើតទំព័រ /kiosk ពេញអេក្រង់សម្រាប់កុំព្យូទ័រដែលភ្ជាប់ USB NFC/RFID reader (ប្រភេទ HID — វាយលេខកាតដូច keyboard)។
មាន input focus ស្វ័យប្រវត្តិចាប់លេខកាត → /api/attendance/kiosk → ស្គាល់បុគ្គលិក → mode ស្វ័យប្រវត្តិ (ចូល/ចេញ toggle តាមកំណត់ត្រាចុងក្រោយ) → បង្ហាញ feedback ធំ → reset។
🇬🇧 English
Build a full-screen /kiosk page for a computer with a USB NFC/RFID reader (HID type — types the card id like a keyboard).
A permanently-focused input captures the card id → /api/attendance/kiosk → identify employee → auto mode (toggle IN/OUT from the last record) → big feedback → reset.

បន្ថែមវិធីទី៥៖ Manual/Proxy។ ក្នុងផ្ទាំង Admin (ឬ kiosk), ជ្រើសបុគ្គលិក + ចូល/ចេញ → កត់ត្រាដោយដៃ (method=manual) ករណីភ្លេចទូរស័ព្ទ។ ផ្ញើ Telegram ដូចគ្នា។

supabase/
